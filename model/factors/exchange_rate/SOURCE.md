# XAF/USD exchange rate (`xaf_usd_monthly.csv`)

Monthly implied XAF/USD rate, derived from FAO GIEWS FPMA market-price
records for Cameroon that report the same observation in both local
currency (XAF) and USD (`price_local / price_usd`), averaged across all
Cameroon commodities/markets reporting that month.

Source: FAO GIEWS Food Price Monitoring and Analysis (FPMA) tool,
via https://github.com/tezamo/FPMA (all_commodity_standardized.csv).
Retrieved 2026-08-14. Covers 2005-01 through 2026-01.
